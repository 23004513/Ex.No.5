# EXP 5: COMPARATIVE ANALYSIS OF DIFFERENT TYPES OF PROMPTING PATTERNS AND EXPLAIN WITH VARIOUS TEST SCENARIOS

# Aim:

To test and compare how different pattern models respond to various prompts (broad or unstructured) versus basic prompts (clearer and more refined) across multiple scenarios. Analyze the quality, accuracy, and depth of the generated responses.

### AI Tools Required:

* ChatGPT
* Any web browser

# Explanation:

## Define the Two Prompt Types:

### 1. Naïve Prompt

A naïve prompt is a simple, broad, or unstructured instruction. It provides limited information about the expected output.

**Example:**

> Write a story about artificial intelligence.

This prompt does not specify the characters, length, audience, style, or message of the story.

### 2. Basic / Refined Prompt

A basic or refined prompt provides clear instructions, context, constraints, and the expected format of the response.

**Example:**

> Write a 300-word science-fiction story about a college student who develops an AI assistant. Include three characters, a problem caused by the AI, and a positive lesson at the end. Use simple English.

This gives the AI more information about exactly what is expected.

---

# Prepare Multiple Test Scenarios

The following scenarios were selected to compare naïve and basic/refined prompting:

1. Creative Story Generation
2. Factual Question
3. Summarization
4. Advice and Recommendation

For each scenario, both a naïve prompt and a basic/refined prompt were given to ChatGPT. The generated responses were then compared based on **quality, accuracy, and depth**.

## Basic / Refined Prompt

> Write a 300-word science-fiction story about a college student named Alex who develops an AI assistant named Nova. The AI should initially help the student with academic work but later make a serious mistake. Include a conflict, how Alex solves the problem, and a positive message about responsible use of AI. Use simple English and give the story a suitable title.

### Output from ChatGPT

## **Nova's Mistake**

Alex was a computer science student who loved creating new technologies. One evening, he developed an AI assistant named Nova.

Nova could organize notes, explain difficult subjects, and help Alex prepare for examinations. Within a few days, Alex began depending heavily on Nova.

One morning, Alex asked Nova to prepare a report for his college project. Nova collected information and created the report quickly. Without checking the information, Alex submitted it to his professor.

The next day, Alex discovered that some information in the report was incorrect. His professor asked him to explain the mistakes, and Alex realized that he had trusted the AI without verifying its output.

Instead of blaming Nova, Alex decided to understand what had happened. He checked the sources used by Nova and corrected the incorrect information. He also modified the system so that it would clearly identify information that required verification.

From that experience, Alex learned an important lesson: artificial intelligence can be a powerful tool, but humans must remain responsible for checking and using its results.

Nova became more reliable, and Alex continued developing it with better safety features.

**Lesson:** Technology can help humans make better decisions, but it should not replace human responsibility.

# ANALYSIS OF RESPONSES

## 1. Quality

The refined prompts generally produced higher-quality responses because they clearly explained what the expected output should contain.

For example, instead of simply asking **"How can I learn programming?"**, the refined prompt specified Java, a 30-day duration, two hours per day, placement preparation, and a final project.

Therefore, the response became more useful and actionable.

## 2. Accuracy

Both naïve and refined prompts can produce accurate answers when the question is straightforward. Prompt refinement does not automatically guarantee factual accuracy.

However, a refined prompt can reduce ambiguity by specifying the exact topic, context, and requirements.

Therefore, **prompt clarity improves relevance and consistency, but factual information should still be verified when accuracy is important.**

## 3. Depth

Refined prompts generally produced deeper responses because they explicitly requested explanations, examples, structure, or specific details.

For example, the refined machine-learning prompt requested:

* Definition
* Three types
* Two applications
* Simple language
* Maximum length

This resulted in a more focused response.

## 4. Consistency

Naïve prompts leave many decisions to the AI. Therefore, the response format and level of detail may vary.

Refined prompts provide constraints that make the output more consistent.

## 5. Personalization

The biggest difference was observed in the advice scenario.

The naïve prompt gave general programming advice, while the refined prompt described:

* Student background
* Existing skill level
* Career goal
* Programming language
* Available time
* Duration
* Expected output

As a result, the refined response was much more personalized.

---

# DOES A BASIC PROMPT ALWAYS PRODUCE A BETTER RESULT?

Not necessarily.

For simple questions, a naïve prompt can sometimes produce an equally useful answer.

For example:

> What is the capital of France?

This is already clear and does not require a long or detailed prompt. A refined version would not necessarily provide a significantly better answer.

Therefore, the amount of prompt detail should depend on the complexity of the task.

### Simple Task

**Naïve prompt:**

> What is the capital of France?

This is sufficient.

### Complex Task

**Refined prompt:**

> Explain the causes of climate change to a first-year college student in simple English. Organize the answer into causes, effects, and possible solutions, and provide two real-world examples.

Here, the refined prompt is much more useful because the task has multiple requirements.

---

# KEY FINDINGS

1. Clear prompts generally produce more relevant and structured responses.
2. Refined prompts provide better control over output format and length.
3. Providing context helps the AI understand the user's actual requirement.
4. Specific constraints can make responses more consistent.
5. Refined prompts are particularly useful for complex tasks.
6. Simple questions may not require highly detailed prompts.
7. Prompt refinement improves relevance and usefulness but does not guarantee factual accuracy.
8. Human verification is still important for factual or critical information.
9. The best prompt is not necessarily the longest prompt; it should contain the information necessary to complete the task effectively.

# SUMMARY

The experiment compared naïve and basic/refined prompting patterns across four different scenarios: creative writing, factual questions, summarization, and advice.

The results showed that naïve prompts can generate useful responses, especially for simple tasks. However, basic/refined prompts generally produced responses with better structure, relevance, depth, personalization, and control.

The experiment also demonstrated that prompt engineering is especially important when a task contains multiple requirements or when a specific output format is needed.

---

# CONCLUSION

The comparative analysis demonstrates that **prompt clarity has a significant impact on the quality and usefulness of AI-generated responses**.

Naïve prompts are suitable for simple and straightforward tasks, while basic/refined prompts are more effective for complex tasks requiring specific information, structure, constraints, or personalization.

Therefore, an effective prompt should clearly communicate the **task, context, requirements, constraints, and expected output** whenever necessary.
